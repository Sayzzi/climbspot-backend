# Activities are derived from the Surface

A Contributor states an Ascent's dominant **Surface** (paved, gravel or trail) and never picks Activities: they are derived from a single mapping so that two identical Ascents can never disagree.

| Surface | Running | Trail Running | Road Cycling | Gravel Cycling | Mountain Biking |
| ------- | :-----: | :-----------: | :----------: | :------------: | :-------------: |
| paved   |    ✓    |               |      ✓       |                |                 |
| gravel  |    ✓    |       ✓       |              |       ✓        |        ✓        |
| trail   |         |       ✓       |              |                |        ✓        |

Mixed-surface Ascents are described by their dominant Surface for now; per-stretch surfaces may come later. Hiking is intentionally out of scope.
